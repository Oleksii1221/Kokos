Architecture

Kokos is a polling-based Telegram bot designed for straightforward Docker deployment.

Components

  • app/bot.py - Telegram handlers, commands, and runtime flow.
  • app/url_parser.py - supported URL detection.
  • app/downloader.py - yt-dlp execution and cleanup.
  • app/db.py - PostgreSQL schema and statistics queries.
  • docker-compose.yml - bot, PostgreSQL, and Redis services.

Flow

A message is received, user and chat activity are recorded, supported links are extracted, the cache is checked, and missing videos are downloaded, uploaded, cached, and counted.

Scaling

The current release uses an in-process semaphore for parallel downloads. Redis is included as the foundation for future distributed queues and rate limits.
