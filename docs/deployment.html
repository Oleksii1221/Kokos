Deployment

Kokos deploys as a Docker Compose stack with the bot, PostgreSQL, and Redis.

Windows

Copy .env.example to .env, fill the required values, and run:

start_bot.bat

Linux

docker compose up -d --build
docker compose logs -f bot

Maintenance

Maintenance mode keeps the bot online but disables video processing.

BOT_MAINTENANCE=true docker compose up -d --build
