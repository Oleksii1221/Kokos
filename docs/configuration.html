Configuration

Kokos is configured entirely through environment variables, making it simple to run locally, on a VPS, or inside a managed Docker environment.

Required

  • BOT_TOKEN - Telegram bot token from BotFather.
  • DATABASE_URL - PostgreSQL connection string used by the bot.
  • POSTGRES_PASSWORD - PostgreSQL password used by the database container.

Recommended

  • OWNER_ID - Telegram user ID for owner-only commands.
  • MAX_PARALLEL_DOWNLOADS - concurrent download limit.
  • MAX_VIDEO_MB - maximum accepted video size.
  • PUBLIC_STATS - controls public access to /stats.

Maintenance

Set BOT_MAINTENANCE=true to keep the bot online while disabling video processing.
