Privacy Policy

Kokos stores only the operational data required to run the bot, provide statistics, prevent repeated downloads, and debug failures.

Data collected

User ID, chat ID, usernames, names, language code, chat titles, activity timestamps, supported video links, platform type, processing status, and Telegram file cache identifiers.

Data not intentionally collected

Kokos does not intentionally store message text unrelated to supported video links, payment details, passwords, or private Telegram authentication sessions.

Retention

Operators decide retention based on their deployment needs. Production operators should periodically remove old logs and database backups.

Contact

Contact the repository owner for privacy requests or operational questions.
