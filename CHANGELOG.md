# Changelog

All notable changes to Kokos are documented here.

## 0.1.0 - 2026-06-17

### Added

- Initial Telegram bot based on `aiogram`.
- TikTok and YouTube Shorts link detection.
- Video download and normalization through `yt-dlp` and `ffmpeg`.
- PostgreSQL statistics for users, chats, activity, and link processing.
- Telegram `file_id` cache for repeated video links.
- Docker Compose stack with bot, PostgreSQL, and Redis.
- Windows batch files for start, stop, and maintenance mode.
- Project logo assets.
- Repository governance, security, support, and documentation files.
