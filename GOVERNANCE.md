# Governance

Kokos is maintained by the repository owner.

## Decision Making

The maintainer prioritizes:

- safe operation in Telegram groups;
- clear deployment and recovery steps;
- minimal dependencies;
- predictable data handling;
- compatibility with Docker-based servers.

## Contributions

Contributions are welcome when they align with the project goals. Large changes
should start as an issue or discussion before implementation.

## Maintainer Responsibilities

- Review dependency and security updates.
- Keep release notes clear.
- Avoid accepting changes that encourage spam, harassment, scraping abuse, or
  copyright infringement.
- Keep `master` stable.
