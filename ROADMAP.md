# Roadmap

Kokos is intentionally small and operator-friendly. The roadmap focuses on
reliability, visibility, and safe growth before adding large new features.

## Now

- Stable Docker deployment for small and medium Telegram communities.
- TikTok and YouTube Shorts detection.
- PostgreSQL statistics and Telegram `file_id` caching.
- Maintenance mode for planned downtime.

## Next

- Admin dashboard for statistics and recent processing failures.
- Redis-backed distributed download queue.
- Per-chat rate limits and abuse protection.
- Better media metadata in replies.
- Automated database migrations.

## Later

- Optional webhook deployment mode.
- Multi-worker processing.
- Prometheus metrics.
- Localization for bot messages.
- Backup and restore helper scripts.
